# Trivia Mundi

¡Bienvenido a Trivia Mundi!

Una aplicación de preguntas y respuestas sobre paises de todo el mundo,
desarrollada con **HTML**, **CSS**, **JS**, **Node.js** y **Express**.

## Características

- Preguntas aleatorias sobre capitales, banderas y paises limitrofes.
- Sistema de puntuación, preguntas correctas y control de tiempo, para medir conocimientos.
- Un Ranking con los mejores 20 jugadores

## 📦 Instalación

### Prerrequisitos

Asegúrate de tener instalado:

- [Node.js](https://nodejs.org/)

### Instalación

1. Clona el repositorio en tu maquina.

2. Instalar dependencias:
    - Ejecuta el siguiente comando en la terminal dentro de la carpeta del proyecto:
          ** npm install **

    Esto instalará Express y node-fetch.

3. Ejecutar la aplicación
    - Para iniciar la app, usa:
          ** npm start **


  Si necesita ejecutarla en modo desarrollo con autorecarga, podrías usar
  nodemon (instálalo con ** npm install -g nodemon **) y ejecutalo con:
    - ** nodemon app.js **

4. Pruebas:
    - Abre el navegador y ve a http://localhost:3000.
